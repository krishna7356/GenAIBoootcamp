# GenAI Bootcamp

Welcome to the GenAI Bootcamp project! This repository contains materials and code for learning and practicing Generative AI concepts.

## Overview

This bootcamp covers fundamental and advanced topics in Generative AI, including:
- Large Language Models (LLMs)
- Prompt Engineering
- Fine-tuning and Transfer Learning
- RAG (Retrieval-Augmented Generation)
- Agent Development

## Getting Started

1. Clone this repository
2. Install required dependencies
3. Follow the tutorials and exercises

## Project Structure

- `/tutorials` - Learning materials and guides
- `/exercises` - Hands-on practice problems
- `/projects` - Full-scale project implementations
